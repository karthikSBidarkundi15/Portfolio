# Karthik Bidarkundi — AI/ML Portfolio

A standalone portfolio built with plain HTML, CSS, and JavaScript. It has no framework, package installation, or build step. The resume PDF is included.

## Preview locally

Open `index.html` in a browser. For the most reliable PDF preview, you can also serve this folder with any static file server.

## Publish on Vercel

1. Extract this ZIP and push the files inside `karthik-portfolio` to the root of a GitHub repository.
2. Import that repository into Vercel.
3. Choose the **Other** framework preset and leave the build command and output directory empty.

Vercel will serve `index.html` and its adjacent CSS, JavaScript, resume, and favicon files directly.

To update the site, edit `index.html`, `styles.css`, or `script.js`. Replace `resume.pdf` with your latest resume while keeping the same filename.
